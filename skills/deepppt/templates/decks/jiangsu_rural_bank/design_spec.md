# 江苏农商行课题汇报 — 设计规范

## I. 模板概述

源自江南农商行「硅基员工人机协同平台建设」课题汇报 PDF，适用于银行、金融科技类机构的课题研究汇报、项目方案陈述、技术平台建设汇报等场景。整体风格稳重专业、结构清晰，以深蓝色为主调传递可信赖感，辅以红橙强调色突出关键数据，白色背景保持页面干净通透。主题模式为 light（白色底色），画布格式为 16:9 (960×540)。

## II. 色彩方案

| 角色 | HEX | 用途 |
|------|-----|------|
| 主色（蓝） | `#0066CC` | 标题栏、章节编号、装饰条、卡片顶部色条 |
| 主色深 | `#004D99` | 渐变收尾、深度强调 |
| 强调色（红橙） | `#E94E1B` | KPI 数据数字、关键指标高亮 |
| 文字色 | `#1A1A1A` | 正文、标题文字 |
| 浅灰文字 | `#666666` | 辅助说明、标签 |
| 背景色 | `#FFFFFF` | 页面底色 |
| 卡片底色 | `#F5F7FA` | KPI 卡片、内容卡片背景 |
| 辅助灰 | `#E0E0E0` | 分割线、卡片描边 |
| 辅助绿 | `#00A896` | 架构图/流程图节点（AI 自由使用） |
| 白色文字 | `#FFFFFF` | 深色背景上的文字 |

## III. 字体

使用标准中文商务字体栈，不引入额外字体依赖：

- 标题/章节：`"Microsoft YaHei", Arial, sans-serif` — Bold 700
- 正文/KPI 标签：`"Microsoft YaHei", Arial, sans-serif` — Regular 400 或 Bold 700 按需

## IV. 签章设计元素

1. **蓝色顶部装饰条**：页面标题左侧 4px 宽的蓝色竖条（`#0066CC`），圆角端点
2. **章节编号圆/框**：章节页使用大号蓝色编号作为视觉锚点，可辅以半透明浅蓝圆形背景
3. **卡片顶部色条**：三栏卡片型内容页的每个卡片顶部带有蓝色色条
4. **KPI 数据卡**：红橙大号数字 + 灰色标签，浅灰圆角矩形容器
5. **底部信息栏**：页面底部统一放置页码 + 章节名，细分割线与主内容区隔开
6. **结束页极简线条**：抽象建筑轮廓或极简几何线条，营造留白与专业感
