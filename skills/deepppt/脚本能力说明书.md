## 一、核心定位与流水线

**PPT Master** 是一个 AI 驱动的多格式 SVG 内容生成系统。核心流水线为：

```
Source Document -> 创建项目 -> [模板] -> 策略师 -> [图像生成] -> 执行器(实时预览) -> 质量检查 -> 后处理 -> 导出
```

### 全局执行纪律（9条铁规）
1. **串行执行** -- 步骤必须严格按序执行
2. **阻塞步骤硬停** -- 标记为 BLOCKING 的步骤必须等待用户明确响应
3. **禁止跨阶段打包** -- 不允许提前准备后续阶段的内容
4. **入口门控** -- 每步有前置条件（GATE）必须先验证
5. **禁止推测执行** -- 例如在策略师阶段提前写 SVG
6. **禁止子代理生成 SVG** -- SVG 必须由主代理端到端完成
7. **仅顺序逐页生成** -- 禁止分组批量生成（如5页一组）
8. **每页重读 spec_lock** -- 执行器每页前必须读取 spec_lock.md
9. **SVG 必须手写** -- 禁止通过脚本/代码批量生成 SVG

## 二、7 步主流水线

| 步骤 | 名称 | 角色 | 阻塞 |
|------|------|------|------|
| Step 1 | 源内容处理 | 转换 PDF/DOCX/PPTX/Excel/URL -> MD | 否 |
| Step 2 | 项目初始化 | `project_manager.py init/import-sources` | 否 |

| Step 4 | 策略师阶段 | 八大确认 -> design_spec.md + spec_lock.md | **阻塞** |

| Step 6 | 执行器阶段 | SVG 逐页生成 + 质量检查 + 演讲备注 | 否 |
| Step 7 | 后处理与导出 | 备注拆分 -> SVG 后处理 -> 导出 PPTX | 否 |

## 九、架构总结

### 设计哲学
1. **AI 作为流水线编排者**：人类用户确认策略方向，AI 执行角色切换、内容生成、质量保证
2. **SVG 为核心中间格式**：跨越设计和 PPTX 的通用语言
3. **严格串行 + 精准门控**：7步流水线，每步有前置条件，阻塞点强制人类参与
4. **三层模板架构**：brand（身份） + layout（结构） + deck（完整），支持多模板融合
5. **多后端可插拔**：图像生成（15后端）、图像搜索（4源）、TTS（6后端）
6. **原生 PPTX 输出**：Direct DrawingML 转换（非 PNG 截图），保留矢量精度、动画、讲者备注
